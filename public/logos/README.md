# Kulüp logoları

Bu klasöre kulüp logosu PNG'lerini koyarsan thumbnail oluşturucuda otomatik
kullanılır. Beklenen dosya adları (`src/lib/logos.ts` ile eşleşir):

- `galatasaray.png`
- `fenerbahce.png`
- `besiktas.png`
- `trabzonspor.png`
- `marseille.png`
- `napoli.png`
- `manchester-united.png`
- `real-madrid.png`
- `barcelona.png`

Öneriler:
- Arkaplanı **şeffaf PNG** kullan (daire içine temiz oturur).
- Kare/ortalanmış görseller en iyi sonucu verir.
- Dosya yoksa uygulama takım renkleriyle **telifsiz stilize rozet** çizer.

⚠️ Telif: Kulüp armaları genelde teliflidir/tescillidir. Buraya koyduğun
görsellerin kullanım hakkına sahip olduğundan emin ol.
